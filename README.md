## 🧠 Problem-Solving Patterns

Understanding the *pattern* behind a problem matters more than memorizing the solution. Here's what I'm actively studying:

<details>
<summary>🔑 Hash Map</summary>

**When to use:** Fast lookups, frequency counting, detecting duplicates or pairs in O(1) average time.
**Common problems:** Two Sum, Group Anagrams, Subarray Sum Equals K.
**Key idea:** Trade space for speed — trade an O(n²) scan for an O(n) pass with a lookup table.

</details>

<details>
<summary>🔍 Two Pointers</summary>

**When to use:** Sorted arrays, pair/triplet sums, in-place partitioning, palindrome checks.
**Common problems:** Container With Most Water, 3Sum, Remove Duplicates.
**Key idea:** Shrink the search space from both ends instead of nested loops.

</details>

<details>
<summary>🪟 Sliding Window</summary>

**When to use:** Subarray/substring problems with a contiguous constraint (max sum, longest unique substring).
**Common problems:** Longest Substring Without Repeating Characters, Minimum Window Substring.
**Key idea:** Expand and contract a window instead of recomputing from scratch.

</details>

<details>
<summary>➕ Prefix Sum</summary>

**When to use:** Range sum queries, subarray sum problems.
**Common problems:** Subarray Sum Equals K, Range Sum Query.
**Key idea:** Precompute cumulative sums so any range sum becomes O(1).

</details>

<details>
<summary>🎯 Binary Search</summary>

**When to use:** Sorted data, or any problem where the answer space is monotonic.
**Common problems:** Search in Rotated Sorted Array, Koko Eating Bananas.
**Key idea:** Binary search isn't just for arrays — it works on answer ranges too.

</details>

<details>
<summary>🐢🐇 Fast & Slow Pointers</summary>

**When to use:** Cycle detection, finding midpoints in linked lists.
**Common problems:** Linked List Cycle, Find the Duplicate Number.
**Key idea:** Two pointers moving at different speeds will eventually meet if there's a cycle.

</details>

<details>
<summary>📉 Monotonic Stack</summary>

**When to use:** Next greater/smaller element problems.
**Common problems:** Daily Temperatures, Largest Rectangle in Histogram.
**Key idea:** Maintain a stack that's always increasing or decreasing to answer "next X" queries in O(n).

</details>

<details>
<summary>🌊 BFS (Breadth-First Search)</summary>

**When to use:** Shortest path in unweighted graphs, level-order traversal.
**Common problems:** Word Ladder, Rotting Oranges.
**Key idea:** Explore level by level — first to reach the target is guaranteed shortest.

</details>

<details>
<summary>🌲 DFS (Depth-First Search)</summary>

**When to use:** Exploring all paths, tree/graph traversal, connected components.
**Common problems:** Number of Islands, Path Sum.
**Key idea:** Go deep first, backtrack when stuck.

</details>

<details>
<summary>🔙 Backtracking</summary>

**When to use:** Generating all combinations/permutations under constraints.
**Common problems:** N-Queens, Subsets, Permutations.
**Key idea:** Build a solution incrementally, undo when it violates constraints.

</details>

<details>
<summary>💰 Greedy</summary>

**When to use:** Local optimal choices lead to a global optimum.
**Common problems:** Jump Game, Activity Selection.
**Key idea:** Prove the greedy choice property before trusting it.

</details>

<details>
<summary>🧮 Dynamic Programming</summary>

**When to use:** Overlapping subproblems + optimal substructure.
**Common problems:** Climbing Stairs, Longest Common Subsequence, Knapsack.
**Key idea:** Memoize what you've already solved — never recompute.

</details>

## 💡 Learning Philosophy

- **Understanding > memorizing.** If I can't explain *why* a solution works, I don't actually know it.
- **Mistakes are data.** Every wrong submission tells me exactly where my mental model broke.
- **Revisit, don't avoid.** The problems I struggled with get solved again after a few days — that's where retention actually happens.
- **Complexity is the real scoreboard.** A working solution is step one; an optimal one is the actual goal.
- **Clean code isn't optional.** If it's messy, I don't understand it well enough yet.
- **Consistency compounds.** Small daily reps beat occasional marathon sessions.
